# Connect Four

Two-player Connect Four, played in the terminal. Players take turns dropping X and O into columns 0–6. The first to line up four in a row (across, down or diagonally) wins the Connect 4 World Cup and gets a trophy drawn on screen.

## How to play

```
python3 connect_four.py
```

Uses only standard Python. The trophy is drawn with the built-in `turtle` module.
